# Mürekkep

iPad için el yazısı not uygulaması: 3B mürekkepler, el yazısını metne çevirme, ders klasörleri,
yapay zekâ asistanı ve PDF'lerden video / sesli özet üreten Stüdyo.

- Uygulama: `Murekkep.swiftpm` (Swift Playgrounds / Xcode uygulama paketi, iPadOS 17+).
- Her `main` gönderiminde GitHub Actions uygulamayı Xcode ile derler, iPad simülatöründe açıp
  ekran görüntüsü alır ve imzasız bir IPA üretir. Sonuçlar: **Actions › son çalışma › Artifacts**.
