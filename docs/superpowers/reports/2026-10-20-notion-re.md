# Notion — what it does that matters for Mürekkep

Source: the Notion desktop app's own code, as its service worker cached it on this PC
(`%APPDATA%\Notion\Partitions\notion\Service Worker\CacheStorage`): 1,800 JavaScript bundles,
112 MB, 757 of them named after a feature. Twelve feature bundles were analyzed with REA
(`analyze_javascript_application`, evidence `ev_9ffb02f0…`; 798 modules, static only, nothing executed),
and their user-facing texts (`defaultMessage`) were read. The workspace database `notion.db`
(the user's own pages) was not opened.

## Features worth matching or beating

| Notion feature (bundle) | What it does | Mürekkep today | Plan |
|---|---|---|---|
| AI Meeting Notes (`TranscriptionBlock*`, `MeetingNotesPageViewBlock`) | Records class or meeting audio, transcribes it live (auto-detected language, many languages, speaker separation), writes a summary with custom instructions, asks for consent first. The student setup offers "Record class and meeting notes automatically". | No recording | Batch 4: audio recording synced to ink (tap a word → hear that moment), on-device transcription (Apple speech, TR/EN), summary through the local AI of Batch 3. Consent notice in the UI. |
| Ask AI over everything (`SearchModal`, `FullPageAI`) | "Ask Notion AI to search across all your connected sources to find the best answer"; search filters by date and person. | Assistant answers about the open note | Batch 3: library-wide question answering with citations (page links), search across notes including recognized handwriting. |
| AI block (`AiBlockV2`) | Generates content in the page from mentioned pages; follow-up questions. | Assistant answers in a side panel | Batch 3: "write the answer onto the page" in typed StrokeFont text. |
| Presentation mode (`PagePresentationMode`) | Page as slides, full screen, next/previous, "{current} of {total}", link to a slide. | Single-page mode (Batch 1) | Batch 4: present a notebook full screen with laser pointer — reuses single-page mode. |
| Student home (`NewStudentHomePopup`) | "Set up your home base for school", track applications, record classes. | Library sections and templates | Batch 4: student starter templates (Cornell notes, weekly plan, exam tracker). |
| Drawing (`drawing`) | A basic drawing block; "Images are not supported in drawings yet". | Full ink engine, 3D pens, shapes, PDF annotation | Mürekkep's strength — keep ahead (Batch 2 handwriting model). |
| PDF viewer (`PDFRenderer`) | Fit to page, zoom in/out. | Annotate, go to page, bookmarks, outline, thumbnails (Batch 1) | Already ahead. |

## Limits of this analysis

- Only cached bundles were available (the desktop app itself is not installed); features whose code
  was never downloaded on this PC are missing.
- REA ran on 12 of 1,800 files; three hit its result budget (static facts kept, semantic graph partial).
- Texts show what the UI offers, not how well it works.
